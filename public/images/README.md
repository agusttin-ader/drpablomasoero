# Imágenes del sitio

## Retrato del doctor (hero)

Instagram **no permite** descargar fotos sin login desde el código (API bloqueada).

Por ahora `about/about-01.jpg` y `hero/hero-01.jpg` usan una **foto pública del mismo profesional** tomada del directorio médico [Crontu](https://crontu.com.ar/masoero-pablo) (mismo Dr. Pablo Masoero).

Para usar una foto **directamente de Instagram**:

1. Abrí [@dr_masoero_pablo_rinoplastia](https://www.instagram.com/dr_masoero_pablo_rinoplastia/).
2. Guardá la imagen que quieras (retrato o post).
3. Reemplazá `about/about-01.jpg` y, si querés la misma en el hero, `hero/hero-01.jpg`.
